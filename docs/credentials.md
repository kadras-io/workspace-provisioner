# Credentials

The credentials are stored once, in a central namespace like `kadras-system`, and shared with all the workspaces via [secretgen-controller](https://github.com/carvel-dev/secretgen-controller). For each credential, the package creates a `SecretExport` next to the Secret, allowing the workspaces to import it.

Each credential is referenced by the `name` and `namespace` of its Secret. Both must be set, or neither. A credential that isn't set is not shared.

Updating a Secret in the central namespace updates it in all the workspaces.

## OCI registry

Set `oci.pull_secret` to share the credentials to pull images from the OCI registry.

```yaml
oci:
  pull_secret:
    name: registry-credentials
    namespace: kadras-system
```

The Secret is of type `kubernetes.io/dockerconfigjson`.

```shell
kubectl create secret docker-registry registry-credentials -n kadras-system \
  --docker-server=ghcr.io \
  --docker-username=${GITHUB_USER} \
  --docker-password=${GITHUB_TOKEN}
```

In each workspace, secretgen-controller merges the credentials into the `canonical-registry-credentials` placeholder Secret, which is the image pull secret of the supply chain ServiceAccount. See [image pull secrets](https://github.com/carvel-dev/secretgen-controller/blob/develop/docs/secret-export.md#using-placeholder-secrets). Without `oci.pull_secret`, the placeholder Secret stays empty.

## Cosign

Set `cosign.secret` to share the Cosign key pair used to sign and verify OCI artifacts.

```yaml
cosign:
  secret:
    name: cosign-key-pair
    namespace: kadras-system
```

The Secret holds the `cosign.key`, `cosign.password`, and `cosign.pub` keys, as generated by [`cosign generate-key-pair k8s://kadras-system/cosign-key-pair`](https://docs.sigstore.dev/cosign/key_management/signing_with_self-managed_keys/).

In each workspace, a `SecretImport` imports the key pair, which is attached to the supply chain ServiceAccount.

## Git

Set `git.secret` to share the credentials to access the Git repositories used in the GitOps workflows, hosted on `git.server`.

```yaml
git:
  server: https://github.com
  secret:
    name: git-credentials
    namespace: kadras-system
```

The Secret holds the `username` and `password` keys.

```shell
kubectl create secret generic git-credentials -n kadras-system \
  --from-literal=username=git \
  --from-literal=password=${GITHUB_TOKEN}
```

In each workspace, a `SecretImport` imports the credentials, which are attached to the supply chain ServiceAccount. The `tekton.dev/git-0` annotation scopes them to `git.server` for the Tekton tasks. See [Tekton authentication](https://tekton.dev/docs/pipelines/auth/#configuring-basic-auth-authentication-for-git).
